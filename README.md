# Arcasis

An **OpenAI-powered shopping assistant** that recommends products based on natural conversations. Users can discover and purchase products directly within the app without visiting external websites.

---

## 🎯 Overview

Arcasis leverages AI to understand user needs through conversation and provides personalized product recommendations. The app features a complete e-commerce experience with seamless checkout, all powered by intelligent chat interactions.

---

## ✨ Features

- **🤖 AI-Powered Recommendations**: OpenAI integration for natural product discovery through conversation
- **🛒 In-App Purchases**: Buy recommended products without leaving the app
- **💳 Secure Payments**: Stripe integration for safe and easy transactions
- **🔔 Push Notifications**: Stay updated on orders, deals, and recommendations
- **📊 User Dashboard**: Track orders, view history, and manage preferences
- **🔐 Authentication**: Secure user accounts and data protection

---

## 🛠️ Tech Stack

- **TypeScript** – Type-safe development throughout the entire codebase
- **OpenAI API** – Natural language processing for conversational product recommendations
- **RapidAPI** – Product data integration
- **Redux** – State management
- **Supabase** – Backend and database
- **Stripe** – Payment processing
- **Push Notifications** – Real-time user engagement

## 💡 How It Works

1. **Chat**: Users describe what they're looking for in natural language
2. **AI Analysis**: OpenAI processes the conversation and understands user needs
3. **Recommendations**: AI suggests relevant products from the catalog
4. **Purchase**: Users can buy directly within the app using Stripe
5. **Track**: Dashboard allows users to monitor orders and preferences
